# Report Finanziamenti

Contratti, immatricolazioni e finanziamenti per marchio, letti per mese, trimestre, anno e ultimi 12 mesi, con report PDF in una pagina.

Questa è una **copia in sola lettura**: i dati sono incorporati nella pagina alla data indicata in testata. I mesi nuovi si inseriscono nella versione su claude.ai; poi la copia si rigenera con `python aggiorna.py` e si ripubblica.
